GPIO digitali

La classe machine.Pin gestisce ingressi e uscite digitali. Usa PULL_UP per i pulsanti collegati a massa. Gli interrupt servono per reagire subito a un fronte, ma l’handler deve restare brevissimo.

LED e pulsante
from machine import Pin
import time

led = Pin(2, Pin.OUT)
btn = Pin(4, Pin.IN, Pin.PULL_UP)

while True:
    led.value(not btn.value())   # pulsante premuto = 0
    time.sleep_ms(20)
Interrupt con debounce software
from machine import Pin
import time

ultimo = 0
premuto = False

def on_press(pin):
    global ultimo, premuto
    ora = time.ticks_ms()
    if time.ticks_diff(ora, ultimo) > 200:
        premuto = True
        ultimo = ora

btn = Pin(4, Pin.IN, Pin.PULL_UP)
btn.irq(trigger=Pin.IRQ_FALLING, handler=on_press)

while True:
    if premuto:
        premuto = False
        print("click")

ADC: sensori analogici

Con attenuazione ATTN_11DB l’ingresso copre circa 0–3,3 V. Mediare più campioni riduce il rumore. Qui sotto un potenziometro o un sensore di luce su GPIO 34.

Lettura mediata in millivolt
from machine import ADC, Pin
import time

adc = ADC(Pin(34), atten=ADC.ATTN_11DB)

def leggi_mv(n=16):
    tot = 0
    for _ in range(n):
        tot += adc.read_uv()     # microvolt calibrati
        time.sleep_ms(2)
    return tot // n // 1000

while True:
    print(leggi_mv(), "mV")
    time.sleep(1)
Se read_uv() non esiste nella tua versione di firmware, usa adc.read_u16() * 3.3 / 65535 per una stima in volt.

PWM: LED, servo, motori

Il PWM varia il duty cycle di un’onda quadra. Per un LED o un motore (tramite driver) la frequenza è libera, per un servo standard servono 50 Hz e impulsi da 0,5 a 2,5 ms.

Dissolvenza di un LED
from machine import Pin, PWM
import time

pwm = PWM(Pin(5), freq=1000)
for d in list(range(0, 65535, 2000)) + list(range(65535, 0, -2000)):
    pwm.duty_u16(d)
    time.sleep_ms(20)
pwm.deinit()
Servo da 0 a 180 gradi
from machine import Pin, PWM
import time

servo = PWM(Pin(18), freq=50)

def angolo(a):
    us = 500 + (a / 180) * 2000
    servo.duty_u16(int(us / 20000 * 65535))

for a in (0, 90, 180, 90):
    angolo(a)
    time.sleep(1)

I2C

Due fili (SDA e SCL) per più dispositivi, ognuno con un indirizzo. Prima di tutto fai sempre una scansione: se la lista è vuota, controlla cablaggio e pull-up.

Scansione e lettura di registri
from machine import I2C, Pin

i2c = I2C(0, scl=Pin(22), sda=Pin(21), freq=400000)
print([hex(a) for a in i2c.scan()])

# Esempio MPU6050 (indirizzo 0x68): sveglia e leggi 6 byte di accelerometro
i2c.writeto_mem(0x68, 0x6B, b'\x00')
dati = i2c.readfrom_mem(0x68, 0x3B, 6)
ax = int.from_bytes(dati[0:2], "big", True)
print("ax grezzo:", ax)

SPI e UART

SPI è veloce e usa un pin CS per dispositivo (display, SD, radio). UART è seriale asincrona, tipica di GPS e moduli modem.

SPI: scrittura con chip select manuale
from machine import SPI, Pin

spi = SPI(1, baudrate=1_000_000, polarity=0, phase=0,
          sck=Pin(18), mosi=Pin(23), miso=Pin(19))
cs = Pin(5, Pin.OUT, value=1)

cs.value(0)
spi.write(b'\x01\x02')
risposta = spi.read(2)
cs.value(1)
UART: lettura di righe da un GPS
from machine import UART, Pin

uart = UART(1, baudrate=9600, tx=Pin(17), rx=Pin(16))
while True:
    if uart.any():
        riga = uart.readline()
        if riga:
            print(riga.decode().strip())

Sensori comuni con driver già inclusi

Questi quattro non richiedono installazioni: dht, onewire, ds18x20 e neopixel sono nel firmware, mentre il sensore a ultrasuoni si gestisce con time_pulse_us.

DHT22: temperatura e umidità
import dht
from machine import Pin

s = dht.DHT22(Pin(15))
s.measure()
print(s.temperature(), "°C", s.humidity(), "%")
DS18B20: sonda di temperatura 1-Wire
import onewire, ds18x20, time
from machine import Pin

ds = ds18x20.DS18X20(onewire.OneWire(Pin(4)))
roms = ds.scan()
ds.convert_temp()
time.sleep_ms(750)
print(ds.read_temp(roms[0]), "°C")
NeoPixel: striscia WS2812
import neopixel
from machine import Pin

np = neopixel.NeoPixel(Pin(13), 8)
np[0] = (255, 0, 0)    # rosso
np[1] = (0, 255, 0)    # verde
np.write()
HC-SR04: distanza in centimetri
from machine import Pin, time_pulse_us
import time

trig = Pin(12, Pin.OUT)
echo = Pin(14, Pin.IN)

def distanza_cm():
    trig.on(); time.sleep_us(10); trig.off()
    durata = time_pulse_us(echo, 1, 30000)
    return durata / 58 if durata > 0 else None

print(distanza_cm())
L’HC-SR04 manda 5 V sul pin echo. Usa un partitore (ad esempio 1 kΩ + 2 kΩ) prima di collegarlo all’ESP32.

Avvertenze sui pin

CasoCosa fare
Strapping pin: GPIO 0, 2, 5, 12, 15Influenzano il boot. Non forzarli a livelli sbagliati all’avvio, soprattutto GPIO 12.
GPIO 6–11Collegati alla flash: non usarli.
GPIO 34–39Solo ingresso, senza pull-up o pull-down interni.
ADC2 con Wi-Fi attivoNon funziona. Usa ADC1 (GPIO 32–39).
Livelli logici3,3 V massimi sui pin. Per 5 V usa level shifter o partitore.
Corrente per pinCirca 12 mA consigliati. Per relè, motori e strisce LED usa transistor, MOSFET o driver (ULN2003, TB6612).
Pull-up I2CSe il modulo non li ha, aggiungi 4,7 kΩ verso 3,3 V su SDA e SCL.
S2, S3, C3Pinout diverso: controlla sempre lo schema della tua scheda.

Struttura asincrona del progetto

Con asyncio puoi leggere più sensori a intervalli diversi senza bloccare il programma e senza usare timer o interrupt per tutto.

main.py con due attività parallele
import asyncio
from machine import Pin
import dht

led = Pin(2, Pin.OUT)
sensore = dht.DHT22(Pin(15))

async def lampeggia():
    while True:
        led.toggle()
        await asyncio.sleep_ms(500)

async def leggi_clima():
    while True:
        sensore.measure()
        print(sensore.temperature(), sensore.humidity())
        await asyncio.sleep(5)

async def main():
    asyncio.create_task(lampeggia())
    asyncio.create_task(leggi_clima())
    while True:
        await asyncio.sleep(60)

asyncio.run(main())
