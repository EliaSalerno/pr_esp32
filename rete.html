Rete e Wi-Fi

L'ESP32 nasce per l'IoT, quindi la rete è il suo pane quotidiano. Vediamo tutte le modalità viste nel repository: connessione manuale "a comando", connessione automatica all'avvio tramite boot.py, modalità Access Point e i comandi di diagnostica.

Regola d'oro

L'ESP32 supporta solo reti a 2.4 GHz: non si connette alle reti a 5 GHz.

Connessione Wi-Fi manuale

Colleghiamo l'ESP32 alla rete a comando, senza connessione automatica all'avvio. Utile in fase di test o quando si vuole controllare esattamente quando la scheda si collega.

Prerequisito: il file wifi_config.py deve essere presente sulla scheda. Verifica con mpremote connect COM5 fs ls; se manca, copialo con fs cp wifi_config.py :wifi_config.py.

wifi_config.py
import network
import time

def connect_wifi(ssid, password, timeout=15):
    wlan = network.WLAN(network.STA_IF)

    if wlan.isconnected():
        print("Già connesso:", wlan.ifconfig())
        return wlan

    wlan.active(False)
    time.sleep(1)
    wlan.active(True)
    time.sleep(1)  # dà tempo all'interfaccia di stabilizzarsi

    print(f"Connessione a {ssid}...")
    wlan.connect(ssid, password)

    start = time.time()
    while not wlan.isconnected():
        if time.time() - start > timeout:
            print("Timeout: connessione fallita")
            return wlan
        time.sleep(0.5)
        print(".", end="")

    print("\nConnesso!")
    print("Config di rete:", wlan.ifconfig())
    return wlan
Perché i due time.sleep(1)

Quelle quattro istruzioni apparentemente inutili (active(False) → pausa → active(True) → pausa) sospendono momentaneamente il tentativo di connessione, dando allo stack Wi-Fi il tempo di completare le proprie operazioni prima di connettersi.

Con il file salvato come wifi_config.py (non boot.py né main.py), la scheda non si connette da sola: il blocco if __name__ == "__main__": scatta solo quando il file è eseguito come script principale, non quando viene importato.

Metodo 1 — comando singolo (consigliato)

mpremote connect COM5 exec "import wifi_config; wifi_config.connect_wifi('NOME_RETE', 'PASSWORD_RETE')"

Vedrai l'output in tempo reale: i puntini di attesa, poi "Connesso!" con l'IP assegnato.

Metodo 2 — dalla REPL interattiva

mpremote connect COM5
>>> import wifi_config
>>> wifi_config.connect_wifi('NOME_RETE', 'PASSWORD_RETE')

Per uscire dalla REPL: Ctrl + ].

Import in cache

Un secondo import wifi_config nella stessa sessione non riesegue il modulo (Python lo tiene in cache). Richiama direttamente la funzione connect_wifi(...), oppure riapri la connessione.

Verificare lo stato in qualsiasi momento

mpremote connect COM5 exec "import network; wlan = network.WLAN(network.STA_IF); print('Connesso:', wlan.isconnected()); print('IP:', wlan.ifconfig())"

Se l'IP è tutto a zero (0.0.0.0), la scheda non è connessa in quel momento.

Connessione Wi-Fi automatica all'avvio

Ad ogni accensione o reset, MicroPython esegue automaticamente, in ordine:

  1. boot.py — per configurazioni di basso livello (Wi-Fi, impostazioni hardware).
  2. main.py — per il programma applicativo vero e proprio.

Per la connessione automatica, il file va salvato come boot.py.

Differenza chiave

Nella versione automatica non serve il blocco if __name__ == "__main__":: in boot.py tutto il file viene eseguito linearmente all'avvio, comprese le ultime righe che chiamano connect_wifi(...).

Lo script è lo stesso, con le credenziali inserite direttamente nel file:

# ... funzione connect_wifi identica a prima ...

# Esecuzione automatica all'avvio (nessun blocco if __name__)
SSID = "NOME_RETE"
PASSWORD = "PASSWORD_RETE"
connect_wifi(SSID, PASSWORD)

Copialo sulla scheda rinominandolo boot.py:

mpremote connect COM5 fs cp wifi_config.py :boot.py
  1. VerificaFai un reset fisico (pulsante EN/RST) e collegati subito alla REPL per vedere l'output: Connessione a NOME_RETE... → Connesso! con l'IP.
  2. Controlla l'IP senza rientrare in REPLmpremote connect COM5 exec "import network; print(network.WLAN(network.STA_IF).ifconfig())"
  3. Attenzione al boot.py esistenteSe c'è già, fs cp lo sovrascrive senza avviso. Fai un backup: mpremote connect COM5 fs cp :boot.py boot_backup.py
  4. Per disattivare l'automatismoElimina il file: mpremote connect COM5 fs rm :boot.py
  5. Combina con main.pyAggiungi l'applicazione separata: mpremote connect COM5 fs cp web_server.py :main.py

Così boot.py gestisce solo la rete e main.py il comportamento dell'applicazione.

Comandi di rete con mpremote

Guida rapida per leggere il MAC address e gestire/ispezionare la rete della scheda.

Installazione e connessione

pip install mpremote
mpremote devs                 # elenca porte e schede
mpremote connect COM3         # Windows
mpremote connect /dev/ttyUSB0 # Linux
mpremote connect /dev/cu.usbserial-0001  # macOS
Nota sul quoting

Su Windows usa virgolette doppie all'esterno e singole all'interno. Per codice lungo è meglio salvare uno script .py ed eseguirlo con mpremote run script.py.

MAC address e ID univoco

MAC Wi-Fi station (leggibile)
mpremote exec "import network, ubinascii; print(ubinascii.hexlify(network.WLAN(network.STA_IF).config('mac'), ':').decode())"

Output di esempio: a4:cf:12:34:56:78

MAC in byte grezzi
mpremote exec "import network; print(network.WLAN().config('mac'))"

Output di esempio: b'\xa4\xcf\x124Vx'

MAC dell'Access Point
mpremote exec "import network, ubinascii; print(ubinascii.hexlify(network.WLAN(network.AP_IF).config('mac'), ':').decode())"

Il MAC dell'AP è diverso da quello della station (di solito l'ultimo byte è incrementato).

MAC Bluetooth (BLE)
mpremote exec "import bluetooth; ble = bluetooth.BLE(); ble.active(True); print(ble.config('mac'))"

Restituisce una tupla (tipo_indirizzo, indirizzo). Richiede firmware recente con BLE abilitato.

ID univoco del chip
mpremote exec "import machine, ubinascii; print(ubinascii.hexlify(machine.unique_id()).decode())"

Su ESP32 coincide in genere con il MAC della station (senza i due punti).

Stato dell'interfaccia, IP, netmask, gateway, DNS

Attivare la station
mpremote exec "import network; w = network.WLAN(network.STA_IF); w.active(True); print(w.active())"

Alcune chiamate (scan, config('mac')) richiedono l'interfaccia attiva.

Connessa? / Codice di stato / RSSI
mpremote exec "import network; print(network.WLAN(network.STA_IF).isconnected())"
mpremote exec "import network; print(network.WLAN(network.STA_IF).status())"
mpremote exec "import network; print(network.WLAN(network.STA_IF).status('rssi'))"

Stati utili: STAT_IDLE, STAT_CONNECTING, STAT_GOT_IP, STAT_WRONG_PASSWORD, STAT_NO_AP_FOUND, STAT_CONNECT_FAIL. L'RSSI è in dBm (es. -55 ottimo, -85 debole).

IP, netmask, gateway, DNS
mpremote exec "import network; print(network.WLAN(network.STA_IF).ifconfig())"

Restituisce una tupla (ip, netmask, gateway, dns), es. ('192.168.1.45', '255.255.255.0', '192.168.1.1', '192.168.1.1').

Impostare un IP statico
mpremote exec "import network; w = network.WLAN(network.STA_IF); w.ifconfig(('192.168.1.50','255.255.255.0','192.168.1.1','8.8.8.8'))"

Scansione delle reti Wi-Fi

mpremote exec "import network; w = network.WLAN(network.STA_IF); w.active(True); [print(r) for r in w.scan()]"

Ogni risultato è una tupla: (ssid, bssid, canale, rssi, authmode, hidden). Versione più leggibile:

mpremote exec "import network, ubinascii; w = network.WLAN(network.STA_IF); w.active(True); [print(r[0].decode(), '|', ubinascii.hexlify(r[1], ':').decode(), '| ch', r[2], '|', r[3], 'dBm') for r in w.scan()]"

Valori di authmode: 0 open, 1 WEP, 2 WPA-PSK, 3 WPA2-PSK, 4 WPA/WPA2-PSK.

Hostname

mpremote exec "import network; print(network.hostname())"
mpremote exec "import network; network.hostname('esp32-lab')"

L'hostname va impostato prima di connettersi. Su versioni più vecchie: w.config(dhcp_hostname='esp32-lab').

Modalità Access Point

L'ESP32 può creare una propria rete Wi-Fi alla quale collegarsi direttamente:

mpremote exec "import network; ap = network.WLAN(network.AP_IF); ap.active(True); ap.config(essid='ESP32-AP', password='12345678', authmode=network.AUTH_WPA2_PSK); print(ap.ifconfig())"

Il tipico IP dell'AP è 192.168.4.1.

Vedere la configurazione APap.config('essid'), ap.config('channel'), ap.ifconfig()
Elencare i client collegatinetwork.WLAN(network.AP_IF).status('stations')
Spegnere l'APnetwork.WLAN(network.AP_IF).active(False)

Test di rete

Non c'è ping

MicroPython non ha un comando ping integrato. Ecco le alternative.

Risoluzione DNS
mpremote exec "import socket; print(socket.getaddrinfo('google.com', 80)[0][-1])"
Test di connessione TCP
mpremote exec "import socket; s = socket.socket(); s.settimeout(5); s.connect(('example.com', 80)); print('OK'); s.close()"
Richiesta HTTP (libreria requests)
mpremote mip install requests
mpremote exec "import requests; r = requests.get('http://example.com'); print(r.status_code); r.close()"
Sincronizzare l'ora via NTP
mpremote exec "import ntptime; ntptime.settime(); import time; print(time.localtime())"

L'ora è in UTC. Richiede la scheda connessa a Internet.

Sicurezza

Nel repository sono presenti credenziali Wi-Fi reali in chiaro in step1/wifi_config.py e step3/web_server.py: non dovrebbero essere versionate. Sostituiscile con placeholder o leggile da file esclusi dal controllo di versione.
