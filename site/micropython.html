MicroPython

MicroPython è l'implementazione di Python 3 ottimizzata per girare su microcontrollori con poca memoria e potenza, come l'ESP32. Permette di scrivere Python "vero" per controllare pin, sensori, motori, display e connettersi al Wi-Fi, senza dover imparare C/C++.

Cos'è MicroPython

MicroPython è un linguaggio completo ma essenziale: mantiene la sintassi e gran parte della libreria standard di Python, e aggiunge moduli specifici per l'hardware. Sull'ESP32 i due moduli che userai di più sono machine (pin, bus, timer, sleep) ed esp (accesso a basso livello al chip).

Vantaggi

Nessuna compilazione: scrivi ed esegui subito.

Comodo

Editing via REPL, seriale o trasferimento file.

Potente

Accesso diretto a GPIO, PWM, ADC, I2C, SPI.

La REPL

La REPL (Read-Eval-Print Loop) è il terminale interattivo di MicroPython: digiti un'istruzione e la esegui immediatamente. È su UART0 (TX=GPIO1, RX=GPIO3), a 115200 baud. 

mpremote connect COM3

Perché preferire i file .py

Incollare più righe nella REPL è rischioso: le indentazioni si rompono, i caratteri possono sporcarsi e la connessione può chiudersi. Per programmi veri usa un file .py e trasferiscilo con mpremote fs cp.

Prima occhiata al codice

from machine import Pin
import time

# Un LED collegato al GPIO2
led = Pin(2, Pin.OUT)

# Un pulsante sul GPIO4 con pull-up interno
btn = Pin(4, Pin.IN, Pin.PULL_UP)

led.value(1)        # accende
time.sleep(0.5)
led.value(0)        # spegne
print("Stato pulsante:", btn.value())

Pin e GPIO

I pin disponibili vanno da 0–19, 21–23, 25–27, 32–39. Evita i pin della flash (6–11, 16, 17). Le modalità principali:

  • Pin.IN — ingresso (sensori, pulsanti)
  • Pin.OUT — uscita (LED, relè)
  • Pin.PULL_UP / Pin.PULL_DOWN — resistenza interna
  • Pin.OPEN_DRAIN — uscita open-drain
  • machine.Signal — per invertire una logica (LED attivi su livello basso)

Il ciclo di avvio: boot.py e main.py

Ad ogni accensione o reset, MicroPython esegue automaticamente in ordine:

  1. boot.pyConfigurazione di basso livello: connessione Wi-Fi, impostazioni hardware. Qui il codice viene eseguito linearmente (nessun blocco if __name__).
  2. main.pyIl programma applicativo vero e proprio, eseguito subito dopo il boot.
Combinazione consigliata

Metti la connessione Wi-Fi in boot.py e la logica dell'app (ad es. un web server) in main.py: codice più ordinato e riutilizzabile. Vedi la scheda Rete.

Se il boot "intrappola" la REPL

Se boot.py o main.py contengono un ciclo infinito, premi Ctrl+C appena appare il banner, oppure tieni premuto BOOT durante il reset per saltare l'esecuzione.

Buone pratiche

Organizza il codice

Riutilizza funzioni in file separati (wifi_config.py) e importali dove servono, invece di duplicare il codice.

Gestisci gli errori

Usa try/except, in particolare per rete e sensori: un errore non gestito interrompe lo script.

Attento alla memoria

L'ESP32 ha poca RAM: evita grandi strutture e import non necessari. Salva i dati in flash con giudizio (open()).

Sicurezza

Non scrivere mai password reali nel codice condiviso/versionato: usa placeholder o file esclusi.

import network
import time

def connetti(ssid, password, timeout=15):
    wlan = network.WLAN(network.STA_IF)
    wlan.active(True)
    wlan.connect(ssid, password)
    t = 0
    while not wlan.isconnected() and t < timeout:
        time.sleep(1)
        t += 1
    if not wlan.isconnected():
        print("Connessione fallita")
    return wlan

try:
    wlan = connetti("NOME_RETE", "PASSWORD_RETE")
    print("IP:", wlan.ifconfig())
except Exception as e:
    print("Errore:", e)

Approfondimenti

Differenze con Python "desktop" (CPython)

MicroPython è un sottoinsieme: mancano alcune librerie standard e alcune funzionalità (ad es. thread avanzati, la parte più ricca di typing, molti pacchetti di terze parti). Il codice è comunque in gran parte compatibile. Package manager: mip al posto di pip, con un indice dedicato (micropython.org/pi).

Async/await e asyncio su MicroPython

MicroPython include asyncio: utile per gestire più attività concorrenti (ad es. server web + lettura sensori) senza bloccare il loop. È lo stesso modello usato internamente da Microdot.
